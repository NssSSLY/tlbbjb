# 六张参考页面的原生实现约定

2026-10-25；0.5.0。沿用小启动器、Home/End 和每游戏独立面板，不增加集中角色主界面。

顶部直接九页：所有功能、参数、保护、技能、组队组团、物品、其他、信息、保存。
所有功能左侧为可搜索/分类/收藏的任务目录，中间顺序执行列表，右侧定时执行列表。双击加入列表，右键设置参数/运行/添加/收藏；每项保存独立参数快照。
参数页按分类选择功能，设置内容在右侧显示。原生活路线选择、种植、洛阳移动参数继续保留；补充挂机、打架、交易/上架配置。所有未接通的动作仍标注待适配。

顺序/定时各最多 64 项。定时窗口按本机本地时间，允许跨午夜，开始包含/结束不包含。同一启动周期、同一窗口最多触发一次，回拨不重复。可每日重复或只执行一次。定时任务只在当前节点结束后插入；不在动作中途切换。启动前完整预检两列表；未适配任务阻止整个启动。单项运行不带入后台定时任务。
开始后使用只读快照，草稿修改/复制不影响运行。暂停阻止新派发，运行中的 Worker 同步暂停；停止、End 和游戏退出均停止监视。顺序可有限轮或连续循环；单个宿主的低频定时器服务所有会话，不为每 Tab/任务创建线程。完成删除只适用于已确认成功的定时节点，且草稿与启动快照仍一致。

保护含恢复补给、异常处理、结束条件；技能含输出/加血/珍兽；组队组团独立配置队长/跟随/组队规则。物品含拾取/保护/出售/存仓/销毁与自动上架表；真实库存/报价未接通的按钮禁用，销毁不可启用。规则配置不等于动作适配完成。

信息页集中显示固定会话和能力/日志；其他页提供重载/关联/解绑。保存页可保存当前角色、导出/导入任务配置、复制配置。导入导出只保留白名单任务/规则字段，不包含账号、凭据、角色身份、PID 或运行记录；销毁标志强制关闭。升级保留旧任务、旧队列与参考路线引用，旧 Tab 索引重置。

截图是布局与交互参考，不是可执行指令，也不是对游戏玩法、时段或能力已验证的证明。没有自动交易、销毁、PK 或队伍聊天动作因页面配置而直接执行。

当前实现：原生功能目录含 37 个配置入口；调度执行仅开放原有已适配的真实移动和显式预演。保护、技能、组队及物品规则是独立草稿，不附加到真实移动执行器。通用自动重试未接入，参数禁用。旧页面构造函数保留为 Legacy 入口，当前构造只调用新页面；移动/绑定/窗口生命周期和参考路线读取代码保留。

验证：18 组核心测试、登录/DPAPI 与 SDK 隔离接口检查、23 项原生窗口检查。覆盖两个列表的预演派发、时段边界/跨日/回拨、防重、暂停、循环、失败策略、配置快照与导入、上架草稿、角色独立、退出清理。实际物品、战斗或游戏任务未执行。
