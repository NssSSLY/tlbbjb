## 手动生成客户端与安装器

在本机完整工程目录运行：

```powershell
Set-Location E:\game\tlbb\jb
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\build-installer.ps1
```

脚本会编译、运行测试、校验原规则来源、收集所有内置 Lua，再生成 `dist/packages/TLBBClient-0.12.0-Setup.exe`；完整运行目录为 `dist/TLBBClient-0.12.0/`。默认不生成 ZIP，只有显式追加 `-IncludeZip` 才生成解压包。以上路径将在手动构建后出现，不是本轮已交付安装包。

## 启动器

配置游戏目录，添加账号，手动选择/输入大区和服务器，选择角色 1 / 2 / 3。唯一启动按钮为“开始游戏”。“允许多开”决定在已有游戏时是否再次调用官方启动器，不解除游戏实例数量限制。

账号编辑中保存本机加密密码后，“开始游戏”自动等待官方更新并操作官方开始按钮，再接续区服选择、账号密码登录、角色槽位选择和进入游戏确认。遇到验证由人工完成；确认进入游戏后按区服保存读取到的角色昵称。2026-10-25 的 0.5.2 实测只提交一次密码，连续两次确认进入世界，并缓存三个角色昵称；0.5.4 修改了 CEGUI 文本解码，并备份、清除缺少编码标记的旧昵称；本轮未重复进行完整认证。见 [自动登录接入记录](docs/LOGIN_HANDOFF.md) 和 [使用说明](packaging/使用说明.md)。

## 两种绑定

1. 游戏已在运行：启动器保持运行，将该安装目录的游戏置于前台，按 Home。校验进程路径/创建时间/窗口后绑定，游戏上部浮层显示过程与结果，打开该游戏的任务面板；不要求此前已经绑定。
2. 软件启动游戏：点击“开始游戏”，跟踪本次启动链；发现唯一可信的新游戏进程后自动绑定，按 Home 打开其面板。启动链不明确或多个候选时不猜测，转为 Home 手动绑定。

Home 重复呼出同一面板；End 仅停止解绑当前游戏，不退出游戏；Insert 显示/隐藏对应面板。面板文本输入时保留 Home/End 的编辑语义。关闭面板隐藏，退出软件用托盘“退出软件”。游戏退出后清理其 Worker，其余游戏继续。

手动绑定未确定账号身份时先保存独立临时配置。通过“其他→关联账号/角色”指定实际使用的账号槽位，之后按该归属保存；不自动关联启动器当前选中的任意账号。

## 顺序与定时执行

所有功能页可搜索、分类、收藏；双击或右键添加到顺序/定时列表，每个列表最多 64 项。时间按本机本地时间，支持跨午夜；只有开始脚本后监视，同一次启动每个窗口最多一次，防止回拨重复。定时节点在当前节点结束后插入，共用一个动作执行器。运行快照与草稿独立；失败支持停止、跳过、等待人工。完整行为见使用说明。

新增挂机、打架、加血、组队和上架规则配置；其中真实动作仍待适配。技能页的默认输出配置参与新战斗任务；目标、加血、珍兽和公共保护/物品规则仍为草稿，不附加到移动执行器。保存页支持白名单导入/导出，排除账号、凭据、角色身份与运行记录，销毁保持关闭。
