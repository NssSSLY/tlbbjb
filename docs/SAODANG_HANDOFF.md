# 扫荡副本流程

更新：2026-11-06。入口 `dungeon_002fbab1`，执行 / 结果契约 `saodang_flow_v1`，代码在 `scripts/legacy/dungeons/saodang.lua` 与 `scripts/legacy/modules/saodang.lua`。独立明文规则，不加载原程序通用宿主；规则对照 `原脚本源码/Script64/副本/扫荡副本.lua` 和 `系统/functions.lua` 的 `SDFB_OnStart`。离线测试通过，未实机验证。

这个任务操作游戏的扫荡窗口，不打怪，不算实打。

## 已完成

1. 打开扫荡窗口，打不开时写明原因并停止。
2. 读列表：每个副本的名字、剩余次数、点数、所需点数。有未扫完的优先继续。
3. 选副本：只选勾选的、还有次数、点数够的。点数不够的写明并跳过。
4. 扫荡页：按顺序点没打完的首领，点确定，直到结束提示或全部打完。单个副本最多 1 分钟。
5. 三神幻境宝箱：默认领免费奖励。有天星灵符且打开“允许物品处理”时才用灵符。
6. 结果：扫荡后重新读列表，**剩余次数减少才算扫成**。结果里写明每个副本扫了几次、跳过了哪些、为什么。

|情况|结果|
|---|---|
|至少扫成一次|`done`|
|勾选的副本都没有次数|`already_done`|
|有副本因点数或成就跳过，且一次都没扫成|停止并写明|
|没有勾选任何副本|停止并写明|
|背包满（提示 `FBSD_150126_33`、`_34`）|停止并写明|
|同一副本 3 次次数不变|跳过；如果是未扫完的那个，停止|

## 与原规则不同的地方

|原规则|现在的做法|可能的偏差|
|---|---|---|
|`EatBindItem`、`EatFubenItem` 吃绑定物品和副本食物|**不移植**|背包更容易满|
|`ClearBag` 清理背包|**不移植**（你说过删除类不做）|同上|
|`Bag_SellItem` 出售、`MainBankSaveItem` 存仓|**不移植**|扫荡奖励留在背包，要自己处理|
|背包满时自动出售和存仓后继续|停止并写明|多个副本时可能扫到一半就停|
|天星灵符默认就用（`sshj_usekey=true`）|要打开“允许物品处理”|默认少一份奖励|
|`setmetatable(_G,…)` 切换环境|通过环境表调用，不改全局|没有实机验证过|
|扫荡点数|照常消耗，勾选即视为同意|—|
