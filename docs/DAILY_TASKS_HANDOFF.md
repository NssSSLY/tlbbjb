## 需要实测确认

- **剑纵群雄：** 钩子 `ZongMenPata_OnEvent` 能否拿到关数，以及 `Player:GetZMPTUiGoToInfo`。读不到会明确报错。
- **临危悟道：** 这条链一次走完，中间每步只点存在的选项，最好全程看一遍。修炼和强化是不可逆操作，开关默认关。
- **茗茶：** 任务 ID 1288–1291 和茶叶技能 3677。
- **金针渡劫：** 同样依赖任务大纲读取。
- **天劫楼：** 楼层场景 272–279，每层出口 (82,80)。

## 同时修的 bug

- **主线、新手、金针渡劫的打怪巡点：** `quest_book` 的判断读了一个不存在的字段，附近没怪时根本不走动，所有打怪任务都会在 5 分钟后报“没有进展”。已修，加了回归用例。

- **主线、新手、金针渡劫的交任务计数：** 对话后任务还在但状态变了，也被算成交了一个，回执数字会虚高。现在任务消失才计数。
