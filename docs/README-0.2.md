## 真实移动测试

1. 登录角色，进入洛阳；目标必须距离当前角色不超过 32 格。
2. 打开发布目录中的 TLBB.exe，选择游戏并绑定，等待面板显示真实地图和坐标。
3. 在“运行方式”中选择“真实移动到坐标”，填写目标 X/Y，例如 360、317。
4. 点击“开始任务”。移动模式可将作物留空；次数不用于移动。
5. Lua 读取真实状态后生成移动决策；Worker 调用原生桥接，随后只读采样位置。到达容差内才报告“真实移动完成”。

每次任务最多提交三次移动。人工接管或阻挡导致角色停下超过 1.5 秒后，脚本重新读取位置并决策；连续无进展或任务超时则停止。暂停、停止、解绑会尽可能通过原生移动入口请求在当前位置停止；如游戏已退出或桥接无响应，不会强杀游戏。操作路径已经实现，人工干预、取消及多个真实游戏长期并行仍需现场验证。

真实适配目前仅接受已检查的 Bin64/Game.exe SHA256：`72f4898ee04d2e8a6d94ff6d45cdc183dfa655eae40c31ddc67dcc2099d9c00d`。还会核对进程创建时间、运行中函数签名及对象指针；游戏更新后需要重新适配，拒绝套用旧地址。

桥接通过 Windows 的目标线程消息钩子临时加载本项目 DLL，在游戏窗口线程调用已核对的原生移动分发函数；完成后解除钩子。不会创建远程执行线程、改写坐标或使用系统键鼠。游戏目录文件保持不变。此实现不是官方 SDK，多版本稳定性、更新兼容和长时间运行尚未验证。

## 启动和操作

打开 `dist/TLBBClient/TLBB.exe`，请保留旁边的运行库、插件和 scripts 目录。

1. 默认安装目录为 `E:\game\tlbb`，可在面板修改。
2. 已运行的游戏会出现在会话列表，可点击“绑定所选”，或在正常 Windows 桌面切到游戏按 Home。
3. Home 只绑定/选中；End 解绑该会话并退出对应 Worker，保留游戏本身。
4. Insert 显示/隐藏面板；面板中开始、暂停/恢复、停止任务。Ctrl+Alt+End 请求停止全部任务。
5. 关闭面板时，如系统托盘可用，则隐藏到托盘继续运行。彻底退出请用托盘“退出并停止”。

快捷键只在游戏或客户端面板上下文注册，注册冲突会显示在状态栏。渲染截图不代表快捷键实测，所有快捷键场景仍需现场核对。

“启动游戏”只打开安装目录下的 Launch.exe，并等待新游戏进程后绑定；不自动登录，不自动执行任务，不解除游戏实例数量限制。启动器复杂派生关系和多候选自动匹配仍需进一步适配。

## 洛阳种植测试参数

- 脚本：`scripts/luoyang_plant.lua`。
- 地图：洛阳；当前测试不包含跨地图导航。
- 默认坐标：X=360，Y=317，对应游戏平面 X/Z；两次真实位置已与界面整数坐标对照。
- 作物：种植模式必填，移动模式可留空，暂不假定任何真实种子 ID。
- 次数：1–100；默认一次。
- 到达容差：0.1–5；默认 1。
- 任务超时：10–1800 秒；默认 120 秒，包含暂停时间。

要查看当前可以运行的测试，请绑定一个正在运行的游戏，在作物参数填写测试值，明确选择“流程预演（不操作游戏）”，然后开始。预演包含接近目标、种植请求、延迟确认和指定次数完成，所有预演日志明确标记。它不能用来证明正式游戏播种成功。

面板参数在下一次任务启动时整体应用；本基础版不在正在执行的任务中自动改参数。每个已绑定会话的面板参数、模式、任务进度和日志分别保存于该会话。程序退出保留一份默认参数供下次填写，但角色身份尚未解析，不宣称已实现跨登录的角色配置自动匹配。

## Lua 修改与重载

发布目录中正在使用的是 `dist/TLBBClient/scripts/luoyang_plant.lua`。修改该文件后无需重新编译 EXE：

1. 客户端提示文件变化。
2. 点击“重新加载 Lua”。
3. 新版本先在候选 VM 中加载；语法、任务 ID、上下文结构检查失败则保留旧版本。
4. 预演动作尚未确认时先等待，再切换；兼容的任务上下文保留。

当前只支持任务 ID `luoyang_plant`、上下文 schema 1；Lua 0.2 根据 config.operation 区分移动与种植规则，不是任意任务插件平台。脚本没有 io、os、package、debug、系统输入或进程 API。

## 生命周期和资源保护

- 每个游戏会话一个 Worker，同一个 EXE 以内部分支启动。
- 使用 PID + 创建时间核验身份，进程退出由 Windows 句柄事件通知。
- 游戏退出、End、控制通道关闭均触发会话停止；只清理自己的 Worker。
- 每 VM 16 MiB 分配预算、单次初始化/决策指令和时间预算。
- Workers 分组设置每进程 192 MiB、组提交内存 512 MiB、组 CPU hard cap 10%；游戏进程不加入该 Job。
- UI、控制消息、输出、日志和历史会话有界；当前最多八个活动会话，三会话以自建测试进程验证。
- 这些保护已写入实现，但没有完成真实多游戏长时间负载验证，不能承诺电脑永不卡顿或游戏适配无风险。

## 生成客户端

```powershell
Set-Location 'E:\game\tlbb\jb'
.\tools\build-client.ps1 -Jobs 4
```

脚本会配置、编译、执行测试、部署 Qt/MinGW 运行库并复制 Lua。输出为 `dist/TLBBClient/TLBB.exe`。

生成新版前需要从托盘退出本客户端，不要求关闭游戏。`user-data` 保留；若发布目录的 Lua 与源码不同，覆盖前会备份到 `artifacts/script-backups`。长期维护建议同时更新源码目录 `scripts/luoyang_plant.lua`。
