# 夜探天波府完整流程

更新：2026-11-05。入口 `dungeon_002e1e29`，执行 / 结果契约 `tianbo_flow_v1`，代码在 `scripts/legacy/dungeons/tianbo.lua` 与 `scripts/legacy/modules/tianbo.lua`。独立明文规则，不加载原程序通用宿主；规则对照 `原脚本源码/Script64/副本/夜探天波府.lua`。离线测试通过，未实机验证。

## 已完成

1. 入场：读活动页次数（第 1 页“夜探天波府”），次数已满时输出 `already_done`。核对背包空位，到洛阳穆小妹 (306,245)。团长等团队人数和同场景人数都达到设置后，选普通 `#{YTTBF_220524_05}` 或困难 `#{YTTBF_220524_06}`，只发一次。队员等待进场。
2. 关卡判定：场上还活着的最靠前的首领决定当前关，只进不退。结束依据是提示 187、189、192、199 或首领尸体，进场前已显示的提示不算。
3. 开怪：团长走到首领旁，等本队血量 85%（最多 45 秒），对话一次并依次选 57、85、84、103 中出现的选项。其他人按团队序号站位。
4. 首领机制：

|首领|位置|处理|
|---|---|---|
|云中鹤|(229,250)|俯冲时躲开并停手；连线时按服务器 ID 分到三个方向，站到不碰翎羽的位置；其余时候躲翎羽|
|岳老三|(250,158)|躲分身 10 码并停手；怒鳄袭沙站到两条射线中间；躲横冲直撞；远程站位|
|叶二娘、傀影|(130,150)|躲破甲摧城（离连线 30 度）；躲预警和回刃；打回刃；无敌时停手；按红影 Buff 和血量选目标|
|段延庆|(110,41)|优先打蓝衣大臣；罪缚无间按是否连线站到不同弧段；躲苔杖|
|心魔·延庆太子|(399,92)|优先打紫衣大臣；十方尽诛跑到安全点并集火；躲剑悬日月；远程站位|

5. 转场：在复活点（y>317）时找穆小妹传送（第三关 258，第四关 259，离场 260）。去段延庆先到 (119,99) 找杨小弟选 138。段延庆结束后等游戏送到心魔区域。
6. 离场：到 (406,99) 找杨文广选“离开天波府”“确认”，最多 3 次。
7. 结果：确认离开场景且活动次数恰好增加一轮，才输出 `done`，顺序队列才放行。

## 与原规则不同的地方

|原规则|现在的做法|可能的偏差|
|---|---|---|
|全团血量 85% 才开怪|读不到全团血量，只等本队（最多 45 秒）|其他队有人没满血也会开|
|陷阱按名字判断|名字读不到的陷阱也算危险，半径用当前机制的值|可能多躲玩家放的陷阱|
|心魔十方尽诛按名字|名字读到时按名字；否则陷阱 4 个及以上当作十方尽诛|少于 4 个时按剑悬日月处理|
|连线按团队序号分方向|其他成员的序号读不到，按服务器 ID 排序|所有客户端结果一致，但顺序和原规则不同|
|云中鹤绕开翎羽用 A* 寻路|只选一个安全的靠近点直接走，找不到就等|路径可能穿过翎羽|
|近战远距离技能 `JinGongFarSkill`|未做，有机制时近战超过 3 码不打|机制期间近战输出少一些|
|岳老三分身包括等级 0 的珍兽|读不到等级，只认名字|这种分身不会躲|
|`CheckUseJZDJ`、呆若木鸡等专属技能|未移植，使用角色技能页|—|
|跨线 `ChangeSceneLine`|走到洛阳场景 0，不单独换线|线路不对时由导航处理|

## 需要实测确认

- **陷阱名字：** 如果翎羽、预警、罪缚无间这些是陷阱对象（名字读不到），连线走位和罪缚无间的弧段规则不会用名字触发，只按普通陷阱躲。这是最需要看的一点。
- **活动次数：** 按原脚本 `IsHuodongComplete("夜探天波府",1)` 读第 1 页。
- **段延庆到心魔：** 假定游戏自动送到心魔区域，超过 3 分钟没有进展会停止。
- **离场文字：** “离开天波府”“确认”是原脚本的字面文字。
