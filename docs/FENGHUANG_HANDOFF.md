# 凤凰陵墓完整流程（普通、困难）

更新：2026-11-05。入口 `dungeon_00322b14`（普通）和 `dungeon_0032b023`（困难），执行 / 结果契约 `fenghuang_flow_v1`，代码在 `scripts/legacy/dungeons/fenghuang_normal.lua`、`fenghuang_hard.lua` 与 `scripts/legacy/modules/fenghuang.lua`。独立明文规则，不加载原程序通用宿主；规则对照 `原脚本源码/Script64/副本/凤凰陵墓-普通.lua`、`凤凰陵墓-困难.lua`，两者只有入场选项不同。离线测试通过，未实机验证。

## 已完成

1. 入场：读活动页次数（第 1 页“凤凰陵墓”），次数已满时到时烈风领取后输出 `already_done`。核对背包空位，到时烈风 (186,113，场景 260)，等队伍集合，选 `#{FHCL_240708_295}`，再选普通 `#{FHCL_240708_6}` 或困难 `#{FHCL_240708_158}`。
2. 开始：场内 (54,131) 的杨建月由队长对话 `#{FHCL_240708_162}`，再在地图上选第 26 间。只有时烈风 (46,131) 时先选 `#{FHCL_240708_24}`。
3. 墓室判断：每 3 秒打开一次地图面板，读当前房间和状态。状态 2 是进行中，按事件编号处理；状态 3 是已清理，队长去下一间。
4. 换房：队长沿固定路线走，路线外就找相邻未探索的房间。地图道具数量大于 0 时先用掉（可关）。
5. 五种首领房：

|事件|首领|处理|
|---|---|---|
|3|地陵蛊花 / 蛊墓花妖|躲陷阱，集火毒种籽和毒花，毒蛊入体时离开队友|
|4|岩铸战将|躲陷阱|
|5|暗冥乌犍|躲陷阱，冥厄时离开队友|
|9|镇陵战魂 / 涅槃|打暗夜珠和耀光珠（带相应甲时靠近），躲扇形、凤舞成双、凤影|
|10|霜影|直接打|

6. 五种小游戏房（都先由队长开火凤石雕）：

|事件|名称|处理|
|---|---|---|
|1|险中觅宝|每人按序号去一个金币陷阱|
|2|凤凰奇阵|按身上印记去对应区域（金、木、水、火、土）|
|6|密匙解匣|有钥匙时交给对应凤雕（技能 3），没有时打傀儡|
|7|三元归鼎|按场上的鼎打另外两种元灵|
|8|大破火凤阵|躲火凤，全队打 ID 最小的傀儡|

7. 结束：提示 `FHCL_240708_168` 或涅槃尸体。原脚本没有离场动作，这里等活动次数恰好增加一轮（最多 5 分钟），再等离场（最多 60 秒）。离开后输出 `done`；次数已加但仍在副本内时也输出 `done` 并写明，不继续下一轮。
8. 领取：离开后到时烈风选 `#{FHCL_240708_295}`、`#{FHCL_240708_5}`（可关）。

## 配置

|配置|默认 / 范围|用途|
|---|---|---|
|最低队伍人数 `count_fhlm`|0；0–24|0 表示不限人数，但队员要同场景|
|完成轮数|1；1–20|完成后接续|
|状态等待 / 秒|45；5–180|状态等待|
|每轮战斗 / 秒|3600；30–3600|总上限|
|地图道具 `fhlm_use_items`|开|换房时使用|
|拾取 `fhlm_loot`|开|每间结束后拾取|
|领取 `fhlm_claim`|开|结束后到时烈风领取|

旧队列缺少这些参数时会要求重新添加本项。

## 与原规则不同的地方

|原规则|现在的做法|可能的偏差|
|---|---|---|
|入场前 `Bag_DeleteItem`|不移植，不删除物品|背包满时停止|
|`EatFubenItem(3)` 吃副本食物|未移植|要自己吃|
|首领 `state==6` 时远离|读不到状态，不做|这个阶段可能挨打|
|陷阱按名字给半径|读不到名字，所有陷阱按该首领的半径|可能多躲玩家放的陷阱|
|险中觅宝躲傀儡扇形|读不到朝向，不躲，只走金币|可能挨打|
|大破火凤阵队员跟队长目标|读不到目标，全队打 ID 最小的|效果相同|
|地图道具每次全点|只点数量大于 0 的|少发无效点击|
|近战远距离技能、轻功、瞬移|未移植|有陷阱时近战超过 3 码不打|
|跨线 `ChangeSceneLine`|要求走到场景 260，不单独换线|队员和队长线路不同时不会自动对齐|

## 需要实测确认

- **地图面板：** `AskWeekPveMapBaseInfo`、`AskWeekPveMapInfo` 和 `ZhouchangPVE_SceneFb_Env` 的函数来自原脚本。这里没有用 `setmetatable(_G,…)`，改为通过环境表调用，这一点没有实机验证。如果读不到房间状态，会在 3 分钟没有进展后停止。
- **傀儡和元灵的类型：** 原脚本有的按 NPC 找。这里只攻击敌对目标；如果傀儡不是敌对目标，密匙解匣和大破火凤阵会等到没有进展后停止。
- **交钥匙的技能 3：** 走动作按钮路径，技能不在列表时日志写明。
- **领取选项：** `#{FHCL_240708_5}` 的内容没有确认。如果会花钱，告诉我，我改成默认关闭并加风险开关。
- **通关提示：** `FHCL_240708_168` 和涅槃尸体都没有出现时，不会判定通关。
