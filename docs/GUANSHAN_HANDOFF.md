# 观山海完整战斗流程

更新：2026-11-05。入口 `guanshan`，执行 / 结果契约 `guanshan_flow_v1`，代码在 `scripts/legacy/dungeons/guanshan.lua` 与 `scripts/legacy/modules/guanshan.lua`。独立明文规则，不加载原程序通用宿主；规则对照 `原脚本源码/Script64/副本/观山海.lua`。离线测试通过，未实机验证。

## 已完成

1. 入场：核对背包空位，到大理沈寒洲 (210,51，场景 2)，等队伍集合。队长选 `#{PTFB_191228_02}` 打开入口窗口，读“本周剩余挑战次数”，为 0 时输出 `already_done`。
2. 选层：入口窗口确认后进入选层窗口。队长按设置选层并确认，队员确认。周奖励勾选按设置同步。
3. 逐层推进：场景 749 / 750 / 752 按各自中心处理，换场景时重建战场状态。没有敌对目标时约 6 秒对守关人对话一次，由对话内容决定下一步：
   - `#{PTFB_191228_217}`：队长在升层窗口选下一层；到达离开层数时离开。
   - `#{PTFB_191228_219}`：开启人点击。
   - `#{PTFB_191228_77`：开启人等全队血量 80%、血祭冷却（最多 90 秒）后开启并确认。
   - `#{PTFB_191228_218}`：挑战失败，离开。
4. 开启人：朝覆雨 / 离人偶由队伍前两人开，解谊由第一个峨嵋开（没有峨嵋时队长），其余由队长开。
5. 13 位守关人的机制（`H` 表）：
   - 燕驰野：提示后离首领 6 码，躲落点 11 码。
   - 解谊：酒坛和追击 Buff 时走到酒坛拼酒（技能 3922）。
   - 唐简：躲扇形和残影，打铁蒺藜。
   - 崔璎：集火提示，点名或花心印时离开队友，血量 10–40 时只普攻。
   - 夜来：躲地面蜘蛛网，依次打蜘蛛、蜘蛛网、首领。
   - 傅致远：按武当白 / 黑 NPC 和阴阳值走位。
   - 朝覆雨 / 离人偶：分工、被追击时拉开 11–14 码、躲陷阱。
   - 段思安：躲陷阱，用天龙面板换血蓝，禁用暗器类技能。
   - 霜见：躲扇形。
   - 原微之：躲黑子，去白子，持白子最多的人释放。
   - 慕容信：远离提示，躲示剑扇形，禁用聚星阵·长生、情尽盈血。
   - 无执：按狂慧 / 金钟罩层数敲木鱼（技能 3943），提示后远离。
   - 苏延清：被缠身时等待，最近的人解救（技能 3960），躲各类预警。
6. 打守关人时禁用指点江山、溪山行旅、昭君出塞。
7. 离场与奖励：到设定层数或挑战失败后离开；可选到沈寒洲领奖。
8. 结果：离开场景才算结束一轮。队长回沈寒洲读本周剩余次数，必须比进入前减少才输出 `done`，顺序队列才进入下一项。

## 与原规则不同的地方

|原规则|现在的做法|可能的偏差|
|---|---|---|
|按称号挑魁元弟子|读不到称号，除首领和机制对象外的敌对目标都当弟子优先打|弟子血量筛选类选项（不打弟子 BOSS 血）无法实现|
|首领朝向决定部分扇形|用首领到最新空 NPC 的角度算，不需要朝向|与原规则相同；残影的安全点改为绕残影转开，不再全图搜点|
|按血量选朝覆雨 / 离人偶开启人|队伍前两人开|可能让血少的人开|
|谁开桃花岛、谁开丐帮选项|固定规则，没有做成设置|—|
|领奖前 `Bag_DeleteBagItem` 清背包|不删除物品；背包提示满时写明并停止领奖|要自己整理背包|
|领奖次数按设置（刷完奖励次数）|最多领 3 次，由对话结果决定|—|
|起始层数单独设置|只有一个“挑战层数”，同时用于入场和升层|想入场选最低、升层选最高时做不到|
|勾选队伍人数 / 平均血量 / 平均层数、队长不在离开|未做|入场前的筛选由队长自己把握|
|`HuiShouLiRenOu` 用勒马归鞍召回离人偶|未做|离人偶走远时要靠手动处理|
|反复对话重复点击|同一对话和层数下每种点击只发一次，超过 max(状态等待, 60 秒) 没变化就写明原因并停止|网络卡顿时可能提前停止|

## 需要实测确认

- **机制技能 3922 / 3943 / 3960：** 用动作按钮路径对 NPC 放，先选中目标并核对。没有实机验证过这些技能是否出现在 `EnumAction(i,'skill')` 里；找不到时日志写“技能列表没有机制技能 N，跳过这一步”，战斗继续。
- **窗口控件名：** 入口、选层、升层、层数、阴阳值、原微之按钮都按原脚本的控件名读取。阴阳值的位置解析是按原规则重写的。
- **沈寒洲回来的次数确认：** 假定回沈寒洲后 `#{PTFB_191228_02}` 能再次打开入口窗口读次数。读不到时不算完成并停止。
- **地面对象名字：** 空npc、残影、酒坛、木鱼等要能在对象列表读到名字。陷阱类机制（kind 2）没有名字，这些走 NPC 对象。

## 未接入

- 死亡复活：血量低于停止阈值时写明原因并停止。
- 踢人、删除物品不移植。
- 需已组队，不含自动组队。
