## 已接入的功能

1. scripts/data/reference_routes.json：38 份表、1,094 点。每份含来源文件、行号、编码、原文件 SHA256。不会在运行时访问 mtxjb 目录。
2. “生活”中的钓鱼、采矿、采药，以及“挂机”中的野外刷怪、藏宝图挖宝、马贼等配置页，新增紧凑的“参考路线”下拉框和“坐标预览”。没有增加主标题或集中角色区域。
3. 选择结果保存为 reference_route，含稳定 ID、名称和原文件哈希；每角色独立，队列参数和配置复制沿用同一结构。未复制原角色昵称和旧账号。
4. 预览按原始顺序列出 X / Y / 来源行。关闭后释放表格；同一个编辑器只保留一个预览窗口。
5. 路线库读取最多 512 KiB、128 份路线、单份 2,048 点、合计 4,096 点；任意一项无效则整份拒绝。没有后台轮询或扫描第三方目录。
6. 新数据随完整安装器和 ZIP 放入 scripts/builtin/data/。包里不包含第三方 EXE/DLL、账号数据库、旧日志和配置值。

## 不能直接执行的原因

点表没有说明是采矿、巡逻、刷怪还是通用巡点，也没有 NPC 名、NPC 坐标、传送菜单、资源类型、地图 ID 或通行性。地图文件名仅记录为 map_hint，真实 map 留空。全部保持 purpose=unclassified、verified=false、runtime_enabled=false。

还有两组完全相同的序列：剑阁 / 塔里木 / 大宛 / 昆仑山 / 龙泉；雪原9矿 / 雪原10矿。没有去重丢弃原表，也没有把它们当作已确认的地图专属路线。数据不应填进传送 NPC 目录。

已有 Lua Worker 仍只运行原种植/洛阳移动模块；参考路线只进入配置和预览。真实刷怪、采矿、钓鱼、种植、跨城及副本仍由能力检查拦截。原有游戏哈希、洛阳地图和近距离移动检查均保留。
