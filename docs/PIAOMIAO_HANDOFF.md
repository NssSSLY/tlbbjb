# 挑战缥缈峰完整战斗流程

更新：2026-11-04。入口 `piaomiao`，执行 / 结果契约 `piaomiao_flow_v1`，代码在 `scripts/legacy/dungeons/piaomiao.lua` 与 `scripts/legacy/modules/piaomiao.lua`。独立明文规则，不加载原程序通用宿主；规则对照 `原脚本源码/Script64/副本/缥缈峰(大).lua`、`原脚本源码/Script64/系统/fn缥缈峰.lua`。活动次数、队伍血量等接口复用 `modules/shaoshi.lua`。离线测试通过，未实机验证。

## 已完成

1. 入场：读活动页次数，核对背包空位、队伍人数、同场景及集合位置，到楼兰程青霜 (192,222) 选难度，等待进入场景 261。次数已满时输出 `already_done`。
2. 关卡判定：场上还活着的最靠前的首领决定当前关；看不到任何首领时不回退。
3. 哈大霸 (124,87)：队长“挑战”开怪，远程分散站位。悬枢之痛时 5 码内远离，近战暂停输出。
4. 桑土公：队长按 (40,105)、(41,86)、(37,60)、(56,69)、(72,66) 依次寻找，寻找时珍兽休息，每个新位置重新开怪；队员跟随队长；只剩碧磷僵尸时打僵尸。
5. 乌老大：NPC 在 x=117 时开怪。可选躲毒群到 (78,65)，收到完成提示后继续。对话提示前一关没杀完时返回前一关。
6. 不平道人 / 卓不凡 / 任平生：队长找符敏仪 (158,54) 开启，先打不平道人，再打其余目标。
7. 李秋水：队长找乌老大 (96,41) 选“决战李秋水？”。大群时按提示跑到对应安全点，停手直到结束；躲寒冰；失踪时在四个点位寻找；可选秒杀（不躲大群和寒冰）。
8. 离场与结果：到乌老大 (95,39) 选离开并确定，刷新活动次数，确认恰好增加一轮才输出 `done`，顺序队列才进入下一项。乌老大仍提供决战选项时，不算完成并停止。

## 配置

|配置|默认 / 范围|用途|
|---|---|---|
|难度 `dpmf_type`|普通、初级、中级、高级|入场选项、首领后缀、活动名|
|最低队伍人数|6；3–6|入场集合|
|完成轮数|1；1–20|完成后接续|
|状态等待 / 秒|45；5–180|集合、入场等待|
|每轮战斗 / 秒|3000；30–3600|五关总上限|
|秒杀李秋水 `xzk158`|关|原 msqs|
|乌老大躲毒群 `xzk226`|关|原 ddq|
|小号模式 `piaomiao_xiaohao`|关|哈大霸不输出、乌老大躲毒群|
|拾取 `piaomiao_loot`|开|每关结束请求拾取附近包裹|

旧队列缺少这些参数时会要求重新添加本项。原通用宿主直跑版已被本流程替换。

## 与原规则不同的地方

|原规则|现在的做法|可能的偏差|
|---|---|---|
|入场前 `Bag_DeleteItem` 清理背包|不接入（删除类，按要求不做）；只检查背包有空位|背包杂物不会被清理|
|活动次数：所有难度都查“楼兰大缥缈”第 2 页|按所选难度查对应活动和页码（原脚本定义了这些值但没用）|若游戏实际只有一条记录，会提示没有唯一记录并停止，请反馈|
|首领当前目标 `target`|哈大霸只看距离：悬枢之痛或低血时 5 码内远离|被追但距离较远时不会提前跑|
|乌老大门派 `menpai`|只用 NPC 的 x 坐标判断（x=117 为未开战）|原规则两个条件之一，通常一致|
|陷阱名称（寒冰）|李秋水场上所有陷阱都躲：7 码，没有落脚点时 6 码|可能多躲，包括玩家放的陷阱|
|首领找不到时按已过处理|保留：到点 5 秒（桑土公走完五个点、任平生等 45 秒）后按已过处理|下一关对话会拒绝并退回；最终完成只认活动次数|

## 未接入

- 死亡复活、出窍：血量低于停止阈值或首领恢复 NPC（灭团）时，写明原因并停止。
- 碧玉套换装（`xzk219`，要取仓库并换装备）、副本药、节日活动、换线。
- 无敌 / 神佑走位、切换神佑珍兽、解除负面状态、瞬移 / 加速、拉怪和控制技能（步步生花、定海神针、灭此朝食）、隐身。
- 队员需先取消跟随；需已组队，不含自动组队。
