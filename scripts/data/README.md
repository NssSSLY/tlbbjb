# 参考路线资料

reference_routes.json 来自用户提供的本地 mtxjb/坐标/*.txt，由 tools/analyze-reference-pack.py 转为 UTF-8 JSON。
38 份表、1,094 个点，保留原始顺序、重复点、原文件行号、编码与 SHA256。源目录保持不变。

这些点没有 NPC、传送目标、资源类型、导航网格或坐标系说明。map=null、purpose=unclassified、verified=false、runtime_enabled=false；map_hint 仅是文件名线索。
“雪原9矿 / 雪原10矿”的地图线索记作银皑雪原，并未确认地图归属。名称和用途需要用户在游戏里核对。
剑阁 / 塔里木 / 大宛 / 昆仑山 / 龙泉五表完全相同，雪原两表也完全相同；按原样保留，不能因此视为多条已验证路线。

0.5.0 客户端在“参数”选择钓鱼、采矿、采药、刷怪、挖图、马贼等时显示“参考路线”。选择后保存 ID、名称、原文件哈希和未验证标记，坐标预览不执行游戏动作。
任务流程参数与每角色配置共用该编辑器；复制配置保留引用，未绑定其他角色身份。未适配任务的运行拦截继续生效。

读取上限为 512 KiB、128 条路线、单条 2,048 点、合计 4,096 点。坐标必须为 0–10,000 的有限数，来源行递增，ID 唯一；任意项错误拒绝整份目录。
该资料文件不属于 Lua 动作模块。未来宿主可以把已确认的数据传入有界 Lua 状态机；当前 Lua Worker 不加载此文件、不执行巡点，也不修改洛阳移动的距离和版本检查。

不包含旧 EXE/DLL、账号数据库、登录日志、配置值或自动更新程序。完整安装包递归包含此目录，运行时不依赖原 mtxjb 文件夹。
