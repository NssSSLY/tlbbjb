# 0.15.0 NPC 任务完成校验

古兰玉兑换宝石、领取师徒心连心、幸运快活三改为运行原任务 Lua 字节码，宿主负责接口与完成回执。已完成 / 已达上限会结束本项并继续下一项；提交后未确认反馈会停止，默认不继续队列。

古兰玉参数的“数量含义”可选“本次新增数量”或“持有目标总数”。前者已有 3 颗、设置 1 就再兑换 1 颗；后者已有 3 颗、设置 1 不兑换。统计道具栏与材料栏的同种一级宝石。达到每日上限显示“已达上限”，不会当作数量完成自动删除定时配置。

幸运快活三需要启用本任务的“允许支付”。这三个任务使用游戏内 Lua，旧配置的引擎字段自动升级，兑换清单保持原值。引擎升级后实测请重新启动对应游戏并用新版绑定。

本批只完成上述三个任务的严格日常完成条件，其他原任务仍需逐项适配和实测，目录中的已接入不代表全部任务已核验。本版完成离线 SDK 和自建窗口检查，尚未实机验证这三个任务。

# 0.14.0 集中资源与通用战斗

安装目录只有 `TLBB.exe`（启动器）、`TLBBRuntime.dll`（程序主体、Qt 和运行库）、`TLBBEngine.dll`（游戏内引擎）、`scripts/`（Lua 规则和任务目录）和 `data/`（账号、任务配置、日志）。首次启动会把 `TLBBRuntime.dll` 解到 `data/cache/`，可以随时删除，下次启动重新生成；账号和日志不在这个目录。

Lua 规则都是 `scripts/builtin/` 下的明文文件，直接修改后停止并重新运行任务就生效。覆盖安装会把改过的同名文件换回安装包版本，长期修改建议另外备份。

通用战斗由所有副本规则共用；入场、路线、机关、Boss 机制和通关回执属于各自副本流程。“信息 → 副本接入清单”显示所提供原程序全部 32 个模块的实际接入状态，资源已导入的条目尚需相应宿主适配才能执行，不将游戏内扫荡等同于完整副本战斗流程。

# 0.13.0 战斗维护

绑定已登录的游戏后，进入“技能 → 状态 / 已学技能”，点击“读取本角色技能”。这是读取任务，不施放技能；运行其他任务时按钮禁用。选择一项已学动作，可加入输出、自身治疗、自身增益或珍兽技能配置。不可用状态会随目标、资源和冷却变化，不代表没有学会；冷却数值保留游戏原值。

“人物恢复”默认关闭，填入确实可对自身使用的已学治疗技能后启用。“珍兽策略”默认关闭，需先在游戏中手动让珍兽出战；可设置喂养、生命停止阈值、共生类回血、血祭类回气和手动战斗技能。恢复必须观察到生命或气量增加；提交后 8 秒没有反馈就停止，不重发该动作。喂养只调用已有口粮的喂养操作，不自动购买、驯养、复活或放生。

当前接入的是自身恢复和普通目标技能。队友治疗、地面选点、阵法、持续引导、复活、自动出战仍待适配；未知门派编号保留原值。首次使用新版需实机核对已学技能、血量、珍兽和施放反馈。若游戏已经加载旧版引擎，需退出该游戏后再用新版绑定，避免继续使用已载入的旧 DLL。

入场方式可选自动或已在副本。自动入场限苏州/苏州休息室，已有队伍默认至少 3 人，不自动组队。“原规则·快速入场”绑定原 ZH/xzk190；人数可显式设置为 3–6。两项仅在原规则的自动入场时启用。输出技能沿用角色技能页或本任务覆盖，血量、间隔、停滞及总超时沿用战斗参数。

棋局场景号修正为原脚本的 61；旧棋局配置里的错误值 3 在读取时归一化。确认同一客户端/服务器 ID 的棋魂死亡两次并离开场景后才报告成功。原规则在初次刷怪前持续等待，外层任务总超时负责兜底。

拾取、自动换线、自动复活、当日次数读取、跨城传送尚未接入。低血量/死亡停止，拾取和换线跳过并记录；完成判断仅针对本轮。代码与离线检查通过不等于真实游戏已通关。

安装器由用户手动构建，默认不生成 ZIP。

## 0.11.0 执行引擎

原脚本任务默认选择“游戏内 Lua”：Lua 5.4 在对应游戏进程内运行，GetLuaValue 直接执行游戏 Lua，宿主接口同步返回；Worker 每 500 ms 查询状态。可选“外部兼容”沿用旧方式。独立每日签到和登录仍用专用流程。

任务修改下次运行生效；新模块可放在 scripts/builtin/legacy/modules，使用 LoadScript("文件名不含扩展名")。新增已注册游戏 Lua API 不必改 C++；原程序的未知原生 ABI 仍需适配，不能把所有原脚本直接复制后当作可运行。

允许支付/交易/下线开关只约束兼容接口；任意 GetLuaValue 直调无法被这些开关全面约束，也可能删除物品。只运行自己信任的脚本。Lua 5.4 限额 16 MiB，游戏 Lua 共享游戏内存，不在该上限内。指令预算不能抢占游戏内部 C 函数，不能保证任意脚本不会卡顿。结束/停止销毁任务，主控消失或五秒无状态查询时停止；游戏窗口线程须仍能运行。

运行文件中原三个桥接 DLL 已合并为 TLBBEngine.dll；保留 Qt Core/Gui/Widgets 与必要运行库。升级安装器只清理已知旧运行文件，保留 data、logs、scripts/user。此版完成离线验证；真实副本和多开长时间性能尚待实测。


运行同目录 TLBB.exe。软件目录需可写，账号、角色槽位、任务参数保存在本目录 data/，日志和缓存也在本目录。无需安装 Qt、Lua 或开发工具。

## 两种绑定方式

1. 已开游戏：软件运行时，把配置目录下的游戏置于前台，按 Home；游戏上部显示绑定提示，随后打开这个游戏自己的任务面板。未绑定游戏也可直接按 Home。
2. 从软件启动：填写游戏目录，选择账号/大区/服务器/角色槽位，点击唯一的“开始游戏”。识别到本次启动链创建的游戏后自动绑定；在游戏按 Home 打开其面板。启动链不明确时不猜测，按 Home 手动绑定。

End 仅停止并解绑当前游戏，不退出游戏。Insert 显示/隐藏当前面板。关闭面板默认隐藏；退出整个软件请用托盘“退出软件”。游戏退出会结束对应 Worker，其余游戏继续。

未勾“允许多开”且已有游戏时不再启动第二个；勾选后允许再次调用官方启动器。这不会解除游戏自身的双开/多开限制。

## 账号与角色

添加或编辑账号，填写账号密码并勾选“保存密码以自动登录（本机加密）”，再配置完整的大区、服务器名称和角色 1/2/3，点击“开始游戏”。软件等待官方更新完成后自动操作官方开始按钮，再选择区服、填充账号密码、选择角色并进入游戏。旧版未保存的密码需要重新输入；密码不会写入 Lua、日志或安装包。角色进入游戏确认成功后，槽位名称更新为实际读到的昵称。0.5.2 曾完成一次真实账号的完整登录验证。0.6.0 修正昵称 UTF-8 解码，本轮未再次认证，真实昵称待选角界面重新核对。旧昵称会先备份到 data/migrations/ 再清除，账号、区服、角色槽位和任务保留。

手动 Home 绑定的游戏先独立保存临时配置；可在“其他→关联账号/角色”选择实际账号槽位，随后配置按该归属保存。不得把一个角色关联到其他账号。多个实例同时编辑同一账号槽位时需要使用不同配置归属。

登录时“开始游戏”临时变为“取消登录”，可随时停止本次登录。每次登录只提交一次密码；遇到游戏验证或提示时等待人工完成，超时停止。当前已核对的官方自绘开始按钮会自动操作；官方程序或布局变化时停止并提示，不猜坐标。未选择保存账号时只启动并绑定，需手动登录。软件不会主动关闭已有游戏；同账号再次登录仍可能由游戏服务器断开原角色，应使用不同账号测试。

游戏上部绑定提示为单行，按文字收缩，1.6 秒后收起；打开任务面板即隐藏，详细提示保留面板日志。提示不接收鼠标，也不抢占键盘焦点。

## 任务边界

顶部九页为：所有功能、参数、保护、技能、组队组团、物品、其他、信息、保存。每个游戏保留自己的配置；小启动器不集中展示所有角色任务。

“所有功能”可搜索、分类和收藏 37 项配置入口。双击添加到顺序列表，勾选“双击添加到定时列表”后改变目标；右键可设置参数、运行本项、添加和收藏。“参数”页配置玩法，加入列表时生成独立快照；修改草稿不会改动已经加入的节点，可在列表双击该节点编辑。

顺序和定时列表分别最多 64 项。定时按本机本地时间，允许跨午夜，开始时刻包含、结束时刻不包含，两端不能相同。点击“修改选中”可改对应节点时段。只有启动脚本后才监视；同一启动周期、同一时段只触发一次，重新启动脚本重新计划。每日重复会等待下一天；未勾每日重复则本次只运行一次。定时任务等当前节点完成后插入，结束后继续顺序任务。

顺序列表可循环，0 轮表示不限；单任务“运行本项”不带入主列表或定时监视。启动前预检两个启用列表，未适配任务会阻止整个启动。运行中的快照不受保存、复制和导入影响。暂停同样作用于等待中的监视；停止、End、游戏退出结束该会话的监视和 Worker。

“成功后删除本项”仅在收到成功结果后删除定时节点；节点在草稿中被改过则保留新草稿。失败处理支持停止、跳过、等待人工；等待人工恢复后继续后续节点，不自动重放失败动作。通用自动重试尚未接入，相应参数禁用。

当前仅“所有功能→工具→洛阳坐标移动”的真实移动已适配，限已核对版本、洛阳 32 格内。种植和移动支持明确选择的预演；移动预演只确认到达，不种植。真实种植、技能、NPC、副本、战斗、交易和采集仍待适配。

保护、技能、组队、物品规则当前独立保存为配置草稿，尚不附加到真实移动执行器。自动上架表可编辑物品、定价、价格、位置和拆分；读取背包按钮禁用。销毁始终禁用，等待真实背包读取和预览接入。

多个移动节点可顺序运行；开始前检查全部节点，未适配任务会阻止流程。停止只影响本面板所属游戏。真实多游戏、全屏显示、实际 Home/End 和长期性能需现场测试；本次发布使用自建窗口做两路径绑定和退出清理验收。

## 完整包与 Lua

scripts/builtin/ 是随包 Lua；scripts/user/ 保留用户脚本。新增源码 scripts/ 下的脚本及资源会递归进入下一次完整包，文件哈希记在 data/package-manifest.json。新增任务还需任务描述和适配能力，放入 Lua 文件不代表任意游戏接口已可用。

修改兼容 Lua 规则可候选重载，无需重编 EXE；修改界面或原生能力需重新编译。交付给其他电脑时生成新的完整 Setup.exe 或 full.zip。升级保留 data/ 和 scripts/user/，不要只拷贝单个 EXE。

0.6.0 保留启动期间只读查询等待、请求过期分类和独立脚本子状态；修正实际登录实例的选服调用。官方更新等待最多 10 分钟，自动按开始后等待新游戏最多 90 秒；登录界面就绪最多等待 90 秒，其他普通阶段 45 秒无进展停止，整体登录最多 5 分钟。0.5.2 的完整登录实测证据保留；本版登录桥接 DLL 因昵称 UTF-8 解码变化，尚未重复真实认证。

## 参考路线

在“参数”选择钓鱼/采矿/采药、刷怪/挖图/马贼等，可选择“参考路线”，点击“坐标预览”查看点序和来源行。38 份表、1,094 点来自用户提供的本地资料，文件随包位于 scripts/builtin/data/reference_routes.json，无需保留原参考软件目录。

选择结果随当前角色参数保存，也可随任务流程和配置复制。地图名和用途尚未核对，选择路线不会更改地图字段或直接执行巡点。部分地图表内容完全相同；不能当成传送 NPC、可通行路径或已验证采集点。这些参考点表仍不启用采集、巡点或副本；当前战斗与棋局任务使用独立规则，见末尾说明。

## 保存和迁移

保存页可保存当前角色、导出或导入任务配置。导出白名单不含账号、密码、角色身份、PID 和运行记录；导入先整体校验，销毁标志强制关闭。跨角色复制不复制身份、技能绑定或运行状态。升级保留旧任务、队列和参考路线引用，旧 Tab 位置重置到“所有功能”。

## 等待任务与新参考库

在“所有功能 → 工具 → 等待到指定时间”设置“指定时刻”或“等待时长”。本地时刻使用 HH:mm；已过的时刻等待下一天，时长支持 1–86400 秒，最长等待支持 1–90000 秒。等待时长暂停后不累计；指定时刻暂停后恢复时重新核对当前时间。可加入顺序或定时列表，等待完成后继续后续任务；停止、解绑和游戏退出结束等待。等待不会移动角色或执行游戏操作。

刷怪、采集、挖图和马贼配置新增“天龙助手 ·”前缀的 72 份参考资料，含 29 份坐标表和 43 个地点模板，共 912 点。连同原资料合计 110 份、2,006 点。地图、场景 ID、用途和可通行性尚未在当前游戏核对，选择资料只保存配置，不启用自动巡点、战斗和采集。

从第三方程序静态提取的 318 个字节码模块及 36 份解码源码保存在项目研究目录。本软件包只包含改写后的兼容 Lua 和参考 JSON，不附带原 EXE/DLL、原始字节码、账号或更新器。

## 每日签到（原 Lua 第 1 批）

入口“所有功能 → 日常 → 每日签到”，设置超时（10–300 秒，默认 90）及失败处理，可运行本项或加入顺序/定时列表。此项标记“已接入·待实测”，本轮按用户安排先交付代码与安装包，未向真实角色发起签到。

内置 scripts/builtin/legacy/daily_sign.lua 与用户提供的原文件一致，保留等待、签到、五档累计奖励请求及关闭窗口的顺序。程序补齐 Sleep、GetLuaValue 的本批固定调用和 CloseWindow 接口。未知调用会停止并提示，其他原脚本尚未因此全部可运行。

签到请求最多一次，每档累计奖励最多一次。任务完成必须读到当天标记并连续确认两次；累计奖励只记录已提交请求，不显示未经确认的物品到账。游戏验证窗口等待人工处理，超时停止；发送失败或结果不确定时不自动重试。暂停不推进 Lua 等待，停止、解绑和游戏退出清理本会话，游戏由用户继续控制。

修改签到 Lua 不必重编；当前运行保持已加载规则，下次任务使用新文件。客户端按钮“重新加载 Lua”在签到运行时只提示下次生效，以避免重复提交。新增游戏 API 或其他原脚本需要分批接入其适配层。

寻路使用游戏自带的自动寻路，按实际坐标判断到达；暂停或停止会让角色就地停下。日志会逐条显示寻路、对话选项、请求和按钮点击。任何一步结果不确定都会停止，不会重复提交。

仓库操作会先走到当前城市（洛阳、苏州、大理、楼兰、凤鸣镇、金陵）的仓库 NPC，其他地图回洛阳；仓库开启需要密保验证时请人工完成，超时会提示并结束。取物按物品名称取，绑定/加锁筛选未接入。

扫荡只做扫荡本身：原程序扫荡前后的清理背包、出售和存仓没有执行；系统提示检测未接入，点数不足的提示依靠扫荡界面本身。

合成宝石：1–3 级用低级合成符，4–6 级用高级，7–8 级用超级；金币+交子不足 50 银时先去仓库取 5 金。宝石按名称里的“石”和“N级”识别，合成完成后的存仓没有执行。商会取钱不会像原程序那样自动换线。

尚未接入、会跳过或停止的部分：喊话（等待队伍人数只等待）、组队、坐骑、使用物品、交易、销毁、系统提示检测（领奖类按原规则的次数上限执行）。锦囊宝箱消化、兑换元宝票等需要销毁物品或未核对接口的脚本暂未列入。

原文件逐字节保存在 scripts/builtin/legacy/tlzz/，由原程序字节码还原的规则在 scripts/builtin/legacy/rebuilt/，兼容接口在 scripts/builtin/legacy/compat.lua。修改这些 Lua 不必重装，下次运行该任务生效；运行中修改不影响当前任务。


## 战斗与棋局（0.10.0）

Home 呼出当前游戏的面板，在“所有功能 → 副本”选“珍珑棋局（实打）”或“副本内战斗”，点参数后运行本项，也可加入顺序/定时列表。

棋局可选“自动入场”或“已在副本”。自动入场使用已有队伍（至少三人），从苏州张弈国进入，不自动组队。副本内战斗需填写实际场景 ID 和确认击杀数，不代表整个副本通关。

“技能 → 输出技能”填写游戏里已学技能的准确名称，每行一项；任务参数可以逗号分隔覆盖。都空时基础攻击，任务填“基础攻击”显式覆盖。技能按顺序选可用项，冷却中跳过。血量低于停止值、切图、目标生命长期不变或超时都会停机。暂停、停止、End 请求原地停下；停止未确认时按状态提示人工接管。

该版本完成代码和离线验证，真实选怪、伤害、冷却、停止和棋局通关仍待实测；未标为已通过游戏内验收。未接自动拾取、自动复活、补给与其他副本首领机制。
